# Демо-стенд

Витрина работ: https://archi-tezz.github.io/previews/

## Как показать работу клиенту

1. Положить папку проекта сюда: `E:\kwork\previews\имя-проекта\`
   Внутри обязательно должен быть `index.html`.
2. Двойной клик по `deploy.bat` (или `.\deploy.ps1` в PowerShell).
3. Через 20-60 секунд ссылка живая:
   `https://archi-tezz.github.io/previews/имя-проекта/`

Титульная страница со списком работ собирается сама.

## Что важно помнить

- Репозиторий публичный: всё, что сюда кладётся, видно по ссылке.
  Чужие макеты под NDA сюда не класть.
- Работает только статика: HTML, CSS, JS.
  Для PHP и MySQL нужен обычный хостинг, Pages их не выполняет.
- Папки, начинающиеся с `_` или `.`, в список не попадают.

## Убрать работу

Удалить её папку и снова запустить деплой.
